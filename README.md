# DataPact

DataPact is a Django app that checks recurring data files against user-defined rules. Set parameters once (column types, allowed values, null constraints), and DataPact automatically verifies every new file against them, flagging the exact row and value at fault with a plain-English explanation, an early warning before issues spread downstream.
