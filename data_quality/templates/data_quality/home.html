How DataPact works

  1. Datasets

    A dataset is a file that arrives again and again, such as a monthly enrollment export. Each one has an owner and a source team.

    {% if user.is_authenticated %}
    • Browse datasets
    • Register a dataset
    {% endif %}

  2. Contracts

    A contract lists the rules every file of a dataset must follow: types, ranges, allowed values, formats, no blanks, no duplicates. Contracts are versioned as expectations change.

    {% if user.is_authenticated %}
    • Search contracts
    • See which version is active
    {% endif %}

  3. Validation runs and violations

    Each time a file is checked against a contract, the result is recorded as a validation run. Every rule it broke becomes a violation, and a person records whether it was a data issue or a contract that needs updating. You can ask an AI model for a suggested explanation.

    {% if user.is_authenticated %}
    • Look up violations
    {% endif %}

  4. Insights and reports

    See how validation runs have turned out, and export every run as CSV or JSON.
